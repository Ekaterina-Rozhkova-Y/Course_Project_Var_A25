# Курсовой проект. Вариант 25

### Назначение программы

Моделирование цифрового двойника технологического процесса по контролю вибрации водяного насоса. Программа последовательно принимает показания X, преобразует их в Q и контролирует состояние по нижней границе LCL = 8,00 и верхней границе UCL = 22,00.

### Организация данных

| Данные | Назначение | Структура |
| :--- | :--- | :--- |
| `x` | Текущее показание датчика (вибрация, мм/с) | `double` |
| `Q` | Текущее значение индикатора процесса | `double` |
| `LCL` | Нижняя граница контроля (8.00) | `double` |
| `UCL` | Верхняя граница контроля (22.00) | `double` |
| `sum` | Накопленная сумма всех значений Q | `double` |
| `min` | Минимальное значение Q | `double` |
| `max` | Максимальное значение Q | `double` |
| `avg` | Среднее арифметическое значение Q | `double` |
| `count` | Количество успешно обработанных показаний | `int` |
| `bad` | Количество отклонений от среднего (> 20%) | `int` |
| `i` | Счетчик цикла | `int` |
| `n` | Количество показаний | `int` |

### Математическая модель и пример расчета

Расчет значений Q осуществлялся по следующей формуле:

Q(X) = {
    4 * X, при X < 3
    2 * X + 6, при 3 <= X < 7
    X + 13, при X >= 7
}

**Пример расчета**

*   Контрольный пример: X = 6.32 ; Q = 18.64
*   Пример 1: X = 1.25 ; Q = 5.00
*   Пример 2: X = 4.20 ; Q = 14.40
*   Пример 3: X = 25.00 ; Q = 38.00 (Тревога, так как Q > UCL)
*   Пример 4: X = 15.26 ; Q = 28.26
